แกลเลอรี่ภาพบ้าน

รูปในส่วนนี้มาจากไฟล์จริงในโฟลเดอร์ images/ ของโปรเจกต์ — ทุกคนที่เปิดลิงก์จะเห็นรูปชุดเดียวกันเสมอ

ยังไม่มีรูปในโฟลเดอร์ images/ — ดูวิธีเพิ่มรูปด้านล่าง

วิธีเพิ่มรูปจริงให้ทุกคนเห็น (ทำครั้งเดียว)
  1. ใน repo GitHub ของคุณ สร้างโฟลเดอร์ชื่อ images ให้อยู่ระดับเดียวกับไฟล์ .html นี้
  2. อัปโหลดไฟล์รูปเข้าโฟลเดอร์นั้น เช่น photo1.jpg, photo2.jpg, photo3.jpg (แนะนำตั้งชื่อไฟล์เป็นภาษาอังกฤษ ไม่มีเว้นวรรค)
  3. เปิดไฟล์ .html นี้ด้วยโปรแกรมแก้ไขข้อความ หาโค้ดบรรทัด const PHOTOS = [...] แล้วใส่ชื่อไฟล์ที่อัปโหลดลงไปตามตัวอย่าง
  4. Commit และ push ขึ้น GitHub ตามปกติ รอ GitHub Pages build เสร็จแล้วเปิดดูได้เลย

ตัวอย่างโค้ดที่ต้องแก้ในไฟล์:

const PHOTOS = [
  "images/photo1.jpg",
  "images/photo2.jpg",
  "images/photo3.jpg"
];

ดูตัวอย่างรูปส่วนตัว (ก่อนใส่ไฟล์จริง)

คลิกช่องว่างเพื่ออัปโหลดรูปจากเครื่องนี้ดูตัวอย่างก่อนได้ — รูปกลุ่มนี้จะเห็นเฉพาะบนอุปกรณ์ที่อัปโหลดเท่านั้น ไม่แสดงให้คนอื่นเห็นเมื่อขึ้น GitHub Pages
